How a Kusnap token reads
Names carry the meaning, so they survive a rebrand and read the same in Figma and in the product. Components never use a raw colour; they point to a role, and the role points to a palette.

Swap the palette and every sell button follows; swap a role and only that job changes. The namespace keeps Kusnap’s tokens unique next to any other library.

Do and don’t
Short rules that come with every component, shown with the real thing.

    

      
Do
✓One primary action per view. Everything else steps back to secondary.

      
Don’t
✕Two blue buttons side by side, so the buyer can’t tell which one moves the order forward.

      
Do
✓Stall green only for selling, so sellers learn to look for it.

      
Don’t
✕Green on a buyer action. It blurs which side of the market a button is for.

10
An accessibility pass on the tokens
I measured the text and background pairs in the Figma file against WCAG AA, which needs 4.5:1 for text this size. Two fall short. Each fix is a proposal: change one token, and every screen follows.
